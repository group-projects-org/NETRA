# NETRA
N.E.T.R.A. – Nodal Encrypted Transmission &amp; Retrieval for Assessments, A Zero-Trust (Never Trust – Always Verify) Just-In-Time (JIT) Secure Examination Printing and Forensic Leak Attribution System. It is designed to bring the cryptographic security of Computer-Based Testing (CBT) to traditional offline, pen-and-paper exams.
